# 유럽 여행 · 공개 가이드

도시 간 이동 지도와 식당·카페·와인 추천을 보는 정적 웹 앱입니다. 지도에는 개략 경로와 이동수단 애니메이션을 표시하며, 일시정지와 동작 줄이기를 지원합니다. 도시·장소 검색, 추천 종류 필터, 홈 화면 추가와 공개 자료 오프라인 캐시를 제공합니다. 추천 장소의 영업시간·가격·예약 조건은 방문 전 공식 사이트에서 확인하세요.

개인 이름, 여행 날짜별 일정, 숙소·좌석·예약 상세, 티켓·QR·원본 문서, 암호화 데이터나 서버 편집 기능은 이 공개판에 포함하지 않습니다. 개인 티켓 관리는 이후 별도 Android 앱으로 전환할 계획이며, 이번 공개 웹에는 티켓 등록 절차나 원본을 포함하지 않습니다. APK가 완성됐다고 가정하지 않으며 개인 티켓을 APK에 평문으로 넣지 않습니다.

## 실행 및 검증

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

- `npm run dev`: 로컬 미리보기
- `npm test`: 공개 자료 경계, 검색, 이전 링크 처리, 캐시 정책 검증
- `npm run build`: 명시된 공개 파일만 `dist/`로 복사

## GitHub Pages

[공개 저장소](https://github.com/mmmg0820/trip-public)의 main 브랜치 루트를 게시합니다. 게시 전 테스트와 빌드를 실행하세요. `app.js`, `lookup.js`, 이전 개인 데이터·보관함·이전용 파일을 공개 루트에 남기지 마세요. 빌드는 전체 폴더를 복사하지 않고 공개 파일만 허용합니다. 브랜치 루트 게시에는 빌드의 허용 목록이 자동 적용되지 않으므로 저장소 루트 역시 공개 자료만 유지해야 합니다.

서비스 워커는 공개 파일만 캐시하고 이전 `public-trip-`, `trip-public-`, `honeymoon-` 캐시를 새 버전 활성화 시 정리합니다. 티켓 보관함의 서버 요청이나 개인 데이터는 캐시하지 않습니다. 과거 Git 기록이나 이미 다운로드된 사본은 이 정리로 제거되지 않습니다.
